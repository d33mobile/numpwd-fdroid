numpwd F-Droid repository

numpwd is a fork of FreeOTP that stores only key names. Tap a key, type a password and it shows the six-character code printed by openssl passwd -6 -salt KEYNAME | tr -dc '[0-9]' | head -c6, with the whole digit string (the same pipeline without head -c6) below it.

Add this repo to F-Droid (open on the phone), or add it by hand:
