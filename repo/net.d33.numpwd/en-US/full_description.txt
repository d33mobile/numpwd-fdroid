numpwd keeps a list of key names and turns a key name plus a password into a string of digits. The digits are exactly what this shell pipeline prints when you type the same password at its prompt:

<pre>openssl passwd -6 -salt KEYNAME | tr -dc '[0-9]'</pre>

So you can always recompute them on any computer with OpenSSL, without the app.

<ul>
<li>Only key names are stored. The password is never saved, logged or offered to autofill.</li>
<li>The password and result dialogs block screenshots and screen recording.</li>
<li>Copy button; the clipboard is cleared after 30 seconds and the result closes after a minute.</li>
<li>Tested against hundreds of vectors generated by the openssl binary, including UTF-8 names, names longer than 16 bytes, "$" and "rounds=N$" in names, and long passwords.</li>
<li>No permissions, no network.</li>
</ul>

Note: tr keeps '[' and ']' too, because the brackets are part of its character set, so a key name that contains brackets yields them in the output as well.
